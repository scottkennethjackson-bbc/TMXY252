# TMXY252 – EduMax Admin View

This repository contains the Part 3(a) solution for the Open University **TMXY252 Web Technologies** module.

## Project overview

The project is a prototype implementation of an administrator page for **EduMax**, a virtual learning environment (VLE). The prototype provides a responsive form for creating and publishing an announcement, based on the administrator interface wireframe developed earlier in the assignment.

The prototype was developed to allow the EduMax team to evaluate the usability of the announcement form across different device sizes before further development takes place.

## Features

* Responsive administrator interface for desktop, tablet and mobile screens.
* Bootstrap-based styling with additional custom CSS.
* Navigation consistent with the EduMax administrator interface.
* Form for entering and scheduling an announcement.
* Option to publish an announcement immediately.
* Pre-filled example data.
* Accessible form controls and navigation.
* POST submission to the TM252 form reflector.
* Required `item_ID` hidden field.

## Technologies

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Git

## Validation and accessibility

The completed HTML and CSS were validated using the W3C validation services. The page was also assessed for accessibility using manual checks and the WAVE accessibility evaluation tool.

The prototype was developed incrementally using Git, with changes committed throughout the implementation process.
